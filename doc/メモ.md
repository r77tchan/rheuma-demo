## Next.js のセットアップで分かったこと（16.4.5）

- `create-next-app` は初期設定で `AGENTS.md` を生成する。今回は `--no-agents-md` を付け、一時フォルダで生成してからコピーした。
- `next dev` はAIエージェントを検出すると、既存の `AGENTS.md` の末尾に指示ブロックを書き足す（実測で確認）。`next.config.ts` の `agentRules: false` で防いでいる。この行を消すと、また書き足される。同じ趣旨の指示は、代わりに `AGENTS.md` に書いてある。
- 初期設定で Cache Components と Partial Prefetching が有効。データ取得は既定で動的で、キャッシュしたい箇所に `use cache` を付ける。動的な要素を入れるときに確認する。

## モックの実装メモ

- 構成: 画面の部品は `components/`、ダミー文言は `data/site.ts`。動的にするときは `data/site.ts` の `news` を置き換える。
- ダミー文言の文字数は元の文に揃えている。文字数を変えると折り返しが変わり、高さがずれる。
- 元サイトの文言を使っていないかは、表示文字列を元サイトのHTMLと照合して確認した（完全一致0件）。「お知らせ」のような一般的な語も避けている。
- PC幅（1025px〜）は元サイトと同じく `min-width: 1370px`。1025〜1369pxでは横スクロールが出る。
- 元サイトと変えた点: スライダーの矢印は作っていない（元サイトは白色で見えない）。最後のスライドの次は巻き戻して先頭へ戻る。全画面メニューの高さは下端が切れないよう調整した。子メニューの開閉はスマホ幅だけ。
- 元サイトとの比較は、Chromeで同じ幅に揃えて各ブロックの座標を測って行った（1440 / 900 / 500px）。
