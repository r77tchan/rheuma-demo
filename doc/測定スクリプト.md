# 測定スクリプト

Claude in Chrome の `javascript_tool` に貼って使う。測りたいサイトをタブで開いた状態で実行する。

- `javascript_tool` の結果は千数百文字で切れる。スクリプトは結果をページ内の `<pre>` に書き出すので、`get_page_text` で読む。ページの中身を置き換えるので、続けて測るときは開き直す。
- 同じ幅のiframeをページ内に置いて測る。Chromeのウィンドウを縮めなくてよく、元サイトでも動く（`frame-ancestors 'self'`）。
- 元サイトには間隔を空けて読み込む（スクリプトに待ち時間を入れてある）。
- 全体の確認は本番ビルド（`npm run build`、`npm run start`）で行う。
- 1024px以下のスライダーは5秒で動くので、読み込み後すぐに測る。
- ページ移動を試すときは、隠れた前のページがDOMに残るので、`checkVisibility()` で絞って要素を探す。

## 1. 座標とスタイルを測る

`pages` に「名前: セレクタ」を書く。名前を両サイトで揃えると、結果を比べやすい。`expected` に前回の `rects` を入れると、ずれた項目だけを出す。

```js
const widths = [1440, 900, 390];
const pages = {
  '/news/': { title: '.page-title', h1: '.page-title h1', inner: 'section .inner', A1: 'article', footer: 'footer' },
};
const expected = null; // 元サイトで出た rects の JSON を入れる

const wait = (ms) => new Promise((r) => setTimeout(r, ms));
const hex = (c) => c.replace(/rgb\((\d+), (\d+), (\d+)\)/, (m, a, b, d) => '#' + [a, b, d].map((x) => (+x).toString(16).padStart(2, '0')).join(''));
const style = (el, win) => { const s = win.getComputedStyle(el); return `${s.fontSize}/${s.fontWeight}/${s.lineHeight} c=${hex(s.color)} bg=${hex(s.backgroundColor)} m=${s.margin} p=${s.padding} b=${s.borderTopWidth} r=${s.borderTopLeftRadius} d=${s.display}`; };
const out = [], rects = {};
for (const [url, sels] of Object.entries(pages)) {
  rects[url] = {};
  for (const w of widths) {
    const f = document.createElement('iframe');
    f.src = url;
    f.style.cssText = `position:fixed;left:0;top:0;border:0;opacity:.01;pointer-events:none;z-index:-1;height:900px;width:${w}px`;
    const ready = new Promise((r) => { f.onload = r; });
    document.body.appendChild(f);
    await ready;
    await f.contentDocument.fonts.ready;
    await wait(500);
    const doc = f.contentDocument, win = f.contentWindow;
    const now = { doc: doc.documentElement.scrollHeight };
    for (const [name, sel] of Object.entries(sels)) {
      const el = doc.querySelector(sel);
      if (!el) { out.push(`${url} ${w} ${name}: なし`); continue; }
      const b = el.getBoundingClientRect();
      now[name] = [b.x, b.y, b.width, b.height].map((v) => Math.round(v * 10) / 10);
      if (expected) {
        const e = expected[url]?.[w]?.[name];
        if (e && now[name].some((v, i) => Math.abs(v - e[i]) > 0.6)) out.push(`${url} ${w} ${name}: ${now[name]}（元 ${e}）`);
      } else {
        out.push(`${url} ${w} ${name}: ${now[name]} | ${style(el, win)}`);
      }
    }
    if (expected && expected[url]?.[w]?.doc !== now.doc) out.push(`${url} ${w} 文書の高さ: ${now.doc}（元 ${expected[url]?.[w]?.doc}）`);
    rects[url][w] = now;
    f.remove();
    await wait(800);
  }
}
if (expected && !out.length) out.push('すべて一致');
document.body.innerHTML = '<main><article><pre id="m"></pre></article></main>';
document.getElementById('m').textContent = out.join('\n') + (expected ? '' : '\n\nrects:\n' + JSON.stringify(rects));
out.length;
```

メインの下層ページで使ったセレクタ（左が元サイト、右がこちら）:

| 名前 | 元サイト | こちら |
| --- | --- | --- |
| 帯 / 見出し | `.page-title` / `.page-title h1` | `main > div` / `main h1` |
| パンくず | `.breadcrumb li` | `main nav li` |
| 本文の枠 | `section .inner` | `main section > div` |
| 絞り込み | `.news-cat-list` / `.news-cat-list a` | `main section ul` / `main section ul a` |
| 行 | `article` / `article time` / `article dt span a` | `main article` / `main article time` / `main article dt a` |
| ページ送り | `.pagination` / `.pagination .current` | `nav[aria-label="ページ送り"]` / `[aria-current="page"]` |
| 詳細 | `section .inner > h2` / `> time` / `> p` / `.pager` | `main section h2` / `main section > div > time` / `.article-body p` / `.article-body + div` |

`/rheuma/` で使ったセレクタ（上の表と違うものだけ）:

| 名前 | 元サイト | こちら |
| --- | --- | --- |
| 行のバッジ | `article dt span` | `main article dt > span` |
| 新着欄 | `.top-news` / `.top-news h2` / `.top-news .btn-more a` | `main > section > div:nth-child(2)` / `main h2` / その中の `div:last-child a` |
| グレーの枠 | `.main-menu .inner`、`.associated-disease`、`.symptoms-appear`、`.banner-lecture`、`.top-qa .inner`、`#top-medical-institution .inner`、`.top-library`、`.top-disaster` | `main [aria-label="ダミーの枠"]` の3つ目以降（順番が同じ） |
| 全画面メニュー | `.menu li`（`.navbar-area` を押して開く） | `aria-controls` のIDの中の `li`（`header > button` を押して開く） |

全画面メニューは文言で行を対応させて、`li` の座標を比べる。スマホ幅の見た目は、同じサイトのページに幅390pxの `iframe` を横に並べて、スクリーンショットで見比べる。

## 2. 書体、太さ、色を比べる

座標が揃っても、この差は見つからない。`labels` に両サイトで同じ文言を書いて、同じスクリプトを両サイトで実行し、結果を見比べる。文言で探すので、セレクタを揃えなくてよい。

```js
const url = '/news/';
const labels = ['お知らせ', 'HOME', '財団情報', '2', '›'];

const wait = (ms) => new Promise((r) => setTimeout(r, ms));
const hex = (c) => c.replace(/rgb\((\d+), (\d+), (\d+)\)/, (m, a, b, d) => '#' + [a, b, d].map((x) => (+x).toString(16).padStart(2, '0')).join(''));
const f = document.createElement('iframe');
f.src = url;
f.style.cssText = 'position:fixed;left:0;top:0;border:0;opacity:.01;pointer-events:none;z-index:-1;height:900px;width:1440px';
const ready = new Promise((r) => { f.onload = r; });
document.body.appendChild(f);
await ready;
await f.contentDocument.fonts.ready;
await wait(700);
const clean = (t) => t.trim().replace(/\s+/g, ' ');
const out = labels.map((label) => {
  const hits = [...f.contentDocument.body.querySelectorAll('*')].filter((e) => clean(e.textContent) === label && !(e.firstElementChild && clean(e.firstElementChild.textContent) === label) && e.checkVisibility());
  const styles = hits.slice(0, 3).map((e) => { const s = f.contentWindow.getComputedStyle(e); return `${e.tagName.toLowerCase()} ${s.fontFamily.split(',')[0].replace(/"/g, '')} ${s.fontSize} w${s.fontWeight} ${hex(s.color)} ls${s.letterSpacing} ${s.textDecorationLine}`; });
  return `${label}: ${styles.length ? [...new Set(styles)].join(' || ') : 'なし'}`;
});
f.remove();
document.body.innerHTML = '<main><article><pre id="m"></pre></article></main>';
document.getElementById('m').textContent = out.join('\n');
out.length;
```

## 3. 自分のコードの変更前後を比べる

全要素の座標を `localStorage` に残して比べる。変更前に `mode = 'save'`、変更後に `mode = 'compare'` で実行する。

変更前のコードを動かしたいときは、`git archive HEAD | tar -x -C 作業領域のフォルダ` で展開して `npm ci` し、同じポート3000で起動する。同じ `localStorage` を使える。終わったら `__baseline` を消す。

```js
const mode = 'save'; // 'save' または 'compare'
const path = '/';
const widths = [1440, 1200, 900, 500, 390];

const wait = (ms) => new Promise((r) => setTimeout(r, ms));
const skip = 'script,style,link,template,nextjs-portal,next-route-announcer,[class*="min-w-[1370px]"]';
const snap = (doc) => [...doc.body.querySelectorAll('*')]
  .filter((el) => !el.matches(skip) && !el.closest('nextjs-portal') && el.checkVisibility())
  .map((el) => { const r = el.getBoundingClientRect(); return [el.tagName.toLowerCase(), ...[r.x, r.y, r.width, r.height].map((v) => Math.round(v * 100) / 100)].join('|'); });
const one = async (w) => {
  const f = document.createElement('iframe');
  f.src = `${path}?m=${w}-${Date.now()}`;
  f.style.cssText = `position:fixed;left:0;top:0;border:0;opacity:.01;pointer-events:none;z-index:-1;height:900px;width:${w}px`;
  const ready = new Promise((r) => { f.onload = r; });
  document.body.appendChild(f);
  await ready;
  await f.contentDocument.fonts.ready;
  await wait(700);
  const top = snap(f.contentDocument);
  const text = f.contentDocument.body.innerText;
  f.contentWindow.scrollTo(0, 500);
  await wait(800);
  const scrolled = snap(f.contentDocument);
  f.remove();
  return [w, { top, scrolled, text }];
};
const now = Object.fromEntries(await Promise.all(widths.map(one)));
const out = [];
if (mode === 'save') {
  localStorage.setItem('__baseline', JSON.stringify(now));
  out.push(...widths.map((w) => `${w}px: 要素${now[w].top.length}`));
} else {
  const base = JSON.parse(localStorage.getItem('__baseline'));
  const diff = (a, c) => { const d = []; for (let i = 0; i < Math.max(a.length, c.length); i++) if (a[i] !== c[i]) d.push(`${i}: ${a[i]} -> ${c[i]}`); return d; };
  for (const w of widths) {
    const d1 = diff(base[w].top, now[w].top), d2 = diff(base[w].scrolled, now[w].scrolled);
    const tb = base[w].text.split('\n'), tn = now[w].text.split('\n');
    const texts = [...tb.filter((t) => !tn.includes(t)).map((t) => '-' + t), ...tn.filter((t) => !tb.includes(t)).map((t) => '+' + t)];
    out.push(`${w}px: 座標差 ${d1.length} / スクロール後 ${d2.length} / 文字差 ${texts.length}`, ...d1.slice(0, 5), ...d2.slice(0, 3), ...(w === widths[0] ? texts.slice(0, 20) : []));
  }
}
document.body.innerHTML = '<main><article><pre id="m"></pre></article></main>';
document.getElementById('m').textContent = out.join('\n');
out.length;
```

## シェルの注意

- zshでは `for path in ...` と書かない。`path` は `PATH` とつながっているので、`curl` などが見つからなくなる。
- `grep --include=*.js` の `*` はzshが先に展開してエラーになる。`--include='*.js'` と引用符で囲む。
